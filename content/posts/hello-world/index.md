This is a starter post. Copy this folder to `content/posts/<your-post>/`, update the frontmatter, and write in Markdown. Set `draft: false` to publish.

## Formatting

Regular paragraphs, [links](https://github.com/coderbirju), **bold**, and `inline code` all work.

```go
func main() {
	fmt.Println("hello, world")
}
```

Images placed next to `index.md` can be embedded with `![alt text](./image.png)`.
